Privacy Policy

Last updated: 30 September 2026

What this is

PaidNoMore uses a private automation tool that connects only to the channel owner's own Google account. It is used by one person, the owner, to manage the channel's own files. It is not a service for the public.

What the tool accesses

With the owner's permission, it can read and write Google Sheets and Google Drive files that belong to the owner. These hold the channel's content plan, scripts, logs and video files.

What we collect

We do not collect, store or process personal data about visitors or any other person. This website has no forms, no accounts, no analytics and no advertising.

How Google data is used

Google data is used only to run the owner's own channel workflow. It is not sold, shared with third parties, used for advertising, or used to train AI models. No person reads it except the owner.

The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can remove the tool's access at any time at myaccount.google.com/permissions.

Contact

Questions can be raised on the PaidNoMore GitHub page.
